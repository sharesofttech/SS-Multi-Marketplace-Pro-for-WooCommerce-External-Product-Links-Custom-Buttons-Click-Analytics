Replace WooCommerce Add to Cart buttons with custom external marketplace buttons (Free Version - Limited to 5 Products)

== Description ==

SS MultiMarketPlace allows you to replace the default WooCommerce "Add to Cart" button with custom external marketplace buttons like Amazon, Flipkart, Ajio, Myntra, and more.

**Free Version Features:**
* Add marketplace buttons to up to 5 products
* Basic button customization (text prefix, default icon)
* Simple button display controls
* Compatible with all WooCommerce themes

**Free Version Limitations:**
* Maximum 5 products with marketplace buttons
* Basic styling options only
* No advanced analytics
* No bulk import/export functionality
* No app-specific custom colors & icons

**Pro Version Features:**
* Unlimited products with marketplace buttons
* Advanced analytics with geolocation tracking
* App-specific custom colors and icons (Amazon orange, Flipkart blue, etc.)
* Bulk import/export via CSV
* Advanced styling controls
* Priority support and updates

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/ss-multimarketplace` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Make sure WooCommerce is installed and activated
4. Go to Multi Marketplace → Settings to configure your preferences
5. Edit any product and scroll to the "Multi Marketplace" tab to add marketplace buttons

== How to Use ==

1. **Add Marketplace Buttons:**
   - Go to any WooCommerce product edit page
   - Scroll down to the "Multi Marketplace" tab
   - Add marketplace name (e.g., "Amazon") and product URL
   - Save the product

2. **Configure Settings:**
   - Go to Multi Marketplace → Settings
   - Set button text prefix (e.g., "Buy on")
   - Upload default icon for all buttons
   - Configure basic display options

3. **View Results:**
   - Visit your product pages to see the custom marketplace buttons
   - Buttons will appear instead of or alongside the Add to Cart button
